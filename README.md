One pager CV, printer friendly.
Print on A4. Letter tested on Safari, Chrome, Firefox.

## Env

```
PHONE=your phone number
EMAIL=your email address
```

## Develop

```
pnpm dev
```

Night view is the bulb in the top corner. It is stored in the browser.

## Deploy

This site is a Next.js app. Connect the GitHub repo in Vercel and deploy `master`.
`vtrofin.github.io` is a GitHub Pages hostname. Vercel cannot serve that address.
